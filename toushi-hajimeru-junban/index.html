投資を始める前に、決めておくこと——順番だけ、静かに整理する

2026年9月20日(リンクを追加 9月23日)

文責: うーはい(会社員。金融の専門家ではありません)。生成AIで下書きを作り、運営者が事実確認・加筆修正のうえ公開しています。運営者について

「投資 何から始める」と調べると、商品や口座の名前が先に並びます。ただ、商品を選ぶ前に決めておくことがある、という説明は公的機関の資料にも見られます。

この記事は、その順番を6つに分けて地図のように示す入口の記事です。6つの並びは、金融庁や日本証券業協会などの資料をもとに、この記事で並べ直したものです。公的機関が示した唯一の順序ではありません。各論はサイト内の別記事へ送ります。特定の商品や会社を勧める記事ではありません。

数字は最小限にとどめ、いずれも2026年9月時点のものです。

こんな方に向いています

  • 投資に興味はあるが、何から調べればよいか分からない
  • 制度・商品・口座を、どの順で調べればよいか整理したい

先に要点だけ

①この記事では、順番を「生活防衛資金→目的と期間→制度→商品→口座→続け方」の6つに並べました。

②口座は5番目に置いています。

③投資には元本割れ(投じた金額を下回ること)のリスクがあります。この記事は特定の方法を勧めるものではありません。

1. 生活防衛資金は、投資と別に分けておく

生活防衛資金とは、急な出費や収入の減少に備えて、投資とは別に持っておくお金のことです。

日本証券業協会の教材「投資の時間」には、お金を3つに整理する考え方があります。

  • 日々の生活に必要なお金
  • 近く(数年のうち)使う道が決まっているお金
  • 当面使う予定のないお金

前の2つのお金で投資すると、今の生活や将来の予定に影響が出る可能性があります。そのため、この部分は預貯金で準備し、投資は3つ目のお金で行う、という説明です。

何か月分を確保するかの目安は、金融庁「基礎から学べる金融ガイド」(2023年12月)の図にあります。図には「緊急資金 3カ月〜1年分」と記載されていますが、根拠の説明は付いていません。金融広報中央委員会の「知るぽると」にも、生活費の3か月〜1年分とする一人暮らし向けの記事があります(監修者の作成による目安)。どちらも公的な基準ではなく、目安の一つです。

適切な月数は、家族構成や収入の安定度で変わります。ここでは、投資に回さないお金の範囲を先に決める、という整理にとどめます。家族構成別の目安額は生活防衛資金、いくら・どこに置くかで試算しています。

2. 目的と期間を先に決める

金融庁のNISA特設サイトでは、ライフプランを描き、必要な金額と時期を考えることが説明されています。何のために、いつ使うお金なのかを、投資の前に考える段階です。

リスク許容度(どこまでの損失に耐えられるか)も、この段階で考える要素です。日本証券業協会の教材は、客観と主観の両面から考えることが大切だとしています。客観的な要素は、収入や資産額、投資経験、今後のライフイベントの数などです。主観的な要素は性格的なもので、株価が下がると心配で眠れないといった場合は、リスクを取りすぎないよう注意が必要とされています。

金融ガイドは、生活に無理のない範囲で始めることが大事だとしています。単身か、共働きか、子育て中かといった家計の形で、考え方の重点は変わります。この点は投資を始める考え方は、家計の「形」で変わるで整理しています。

3. 制度は、NISAとiDeCoがよく取り上げられる

国の制度として、NISA(少額投資非課税制度)とiDeCo(個人型確定拠出年金)がよく取り上げられます。どちらも、運用で得た利益に通常かかる税金が非課税になる仕組みがあります。一方で、運用する商品には元本割れのおそれがあります。iDeCoは手数料もかかり、受け取るときに税金がかかる場合もあります。要点だけ並べます(2026年9月時点、金融庁・iDeCo公式サイト)。

NISA

  • 年間の投資上限は、つみたて投資枠が120万円、成長投資枠が240万円で、併用できます
  • 非課税で保有できる生涯の上限は1,800万円で、うち成長投資枠は1,200万円までです
  • 非課税期間は無期限で、口座開設年の1月1日時点で18歳以上が対象です
  • 損失が出ても、ほかの口座の利益との相殺(損益通算)や翌年以降への繰越はできません

iDeCo

  • 自分で掛金を出して運用する私的年金で、掛金は全額が所得控除の対象です(その分、税金の計算のもとになる所得が減ります。課税所得がない方は控除を受けられません)
  • 月5,000円から始められ、原則60歳まで引き出せません
  • 掛金の上限は加入区分で異なり、改定の予定もあるため、最新は公式サイトで確認が必要です

どちらも制度であって、商品ではありません。二つの制度の違いは新NISAとiDeCo、どこが違うのかで整理しています。

4. 商品の種類は、四つを一言ずつ

制度の次に、商品の種類です。金融ガイドと日本証券業協会の説明をもとに、主なものを一言ずつ並べます。

  • 株式: 会社が資金を集めるために発行するものです。配当(会社の利益の一部の分配)などがあります
  • 債券: 国・自治体・会社がお金を借りるために発行するものです。利子が定期的に支払われます
  • 投資信託: 多数の投資家の資金をまとめ、専門家が株式や債券などに投資するものです
  • ETF(上場投資信託): 取引所に上場した(取引所で売買できる)投資信託で、株式と同じように売買できます

いずれも預貯金と違い、元本割れのおそれがあります。主なリスクは価格変動、信用(発行体の経営悪化など)、為替変動(外貨建ての場合)、カントリー(国や地域の情勢)です。リスクとは、リターン(運用で得られる成果)の不確実性、つまり振れ幅のことです。

金融ガイドは、リスクがなくてリターンが高い金融商品はないことも説明しています。「必ず儲かります」「安全・確実・高利回り・元本保証」といった説明をされたときに、疑いを持つこともできる、という考え方です。

あわせて出てくる言葉に「分散」と「複利」があります。分散は、複数の資産・地域・時期に分けることです。複利は、元本だけでなく利息にも利息がつくことです。

投資信託とETFの優劣はここでは扱いません。二つの違いは投資信託とETF、何が違うのか、用語は投資まわりの用語集にまとめています。

5. 口座は、ここまでの整理のあとに置く

口座の開設は、ここまでの整理のあとの段階に置きました。開く時期や、開くかどうか自体は、人によって異なります。

証券口座やNISA口座の開設には、本人確認書類とマイナンバーの告知(番号を金融機関に伝えること)が必要です。マイナンバーカードのほか、番号が記載された住民票の写しと運転免許証などを組み合わせる方法もあります。

NISA口座は1人1口座で、金融機関は年単位で変更できます。開設時には金融機関が税務署に、二重開設がないかを確認します。開設にかかる日数は、金融機関によって異なります。口座を開いて取引する場合も、元本割れのおそれがあります。

金融機関ごとの違い(手数料・取扱商品など)を比べた記事として、証券口座はどう選ぶかがあります。

6. 続け方は、積立と一括の二つの考え方がある

口座のあとは、資金の入れ方です。積立(定期的に一定額を買う)と一括(まとまった資金を一度に買う)の二つの考え方があります。どちらが合うかは一つに決まらず、この記事では優劣を扱いません。

どちらの方法でも、元本割れの可能性はあります。長く続ければ損をしない、という意味でもありません。二つの違いは積立投資と一括投資、何が違うのかで、研究と制度の両面から整理しています。

どの段階でも気をつけたいこと(SNS型投資詐欺)

順番のどこにいても、先に知っておきたいのがSNS型投資詐欺です。金融庁の注意喚起(2025年4月17日更新)では、著名人になりすました広告や偽アカウントから、LINEグループなどへ誘導される事例が示されています。誘導された先で入金を求められます。出金しようとすると、手数料や税金の名目で追加の入金を求められる手口もあります。

国民生活センター(2026年9月1日公表)は、投資資金の振込先に個人名義の口座を指定された場合は詐欺だとして、振り込まないよう注意喚起しています。金融商品を扱う業者が登録を受けているかは、金融庁の事業者検索で確認できます。困ったときの相談先は、消費者ホットライン188です。

おわりに

順番は「生活防衛資金→目的と期間→制度→商品→口座→続け方」と並べました。この並びは一つの整理で、状況によって前後することもあります。制度や数字は動くため、最新の情報は金融庁などの公式情報で確認してください。
