SNSで勧められた投資話の確かめ方、相談先、被害回復の流れ

2026年11月24日

文責: うーはい(会社員。金融の専門家ではありません)。生成AIで下書きの作成と警察庁・金融庁・国民生活センターなどの公表資料との照合を行い、運営者が内容を確認して公開しています。【】は、出典の機関や運営者の整理を示す印です。運営者について

SNSで勧められた投資の話の確かめ方と相談先、被害回復の流れを、2026年11月24日時点の公開資料で整理します。

こんな方に向いています: SNS・LINE・メッセージアプリで投資の話を受け取った方と、そのご家族です。投資を始める前の方、始めたばかりの方を想定しています。扱わないもの: 個別の投資話や業者の真偽の判定、相手への返信の仕方、損失の取り戻し方の助言、法律相談。

先に要点だけ

①【警察庁】確認項目に1つでも当てはまれば、振り込む前に警察へ相談するよう呼びかけ、相談先に#9110を挙げています。

②【金融庁】相手が登録等を受けた事業者かどうかは、金融事業者一括検索で確かめられます。

③【金融庁】振り込んだ後の連絡先に、警察と振込先の金融機関を挙げています。

④【金融庁】振り込め詐欺救済法(詐欺などに使われた口座の残高から被害者へ支払う手続を定めた法律)の支払は、犯人が口座から引き出した後は受けられないと書いています。

  • まだ送っていない方: 登録の確かめ方・確認項目・振込前の窓口 第2章・第3章・第5章
  • 送ってしまった方(口座への振込の場合): 最初の連絡先と支払までの流れ 第5章・第6章。暗号資産・現金で渡した場合は第7章
  • 家族が勧められている方: 確認項目・入金を求められた時の注意・相談先 第3章・第4章・第5章

この記事は警察庁・金融庁などの公開資料の整理で、投資話の真偽の判定・法律相談・投資助言・金融商品の勧誘ではありません。この記事は、金融機関から依頼や対価を受けて書いたものではなく、本文にアフィリエイトリンクはありません(運営方針)。

1. SNS型投資詐欺の規模と、手口の流れ

【運営者の整理】警察庁と金融庁の資料が書く手口の流れを、5段階に要約しました。

  1. SNSの広告やダイレクトメッセージ(DM)から、相手とつながる
  2. グループに招かれ、もうけたという投稿を見る
  3. 投資家やその助手を名乗る人から、振込を指示される
  4. 投資アプリなどの画面に偽の利益が表示され、少額だけ出金できることもある
  5. 出金に手数料などを求められ、やがて連絡が途絶える

【警察庁】令和7年(2025年)の確定値では、SNS型投資詐欺の認知件数は9,523件、被害額は1,288.0億円です。SNS型ロマンス詐欺は5,645件、546.4億円です(2026年6月5日公表)。

【警察庁】SNS型ロマンス詐欺は、恋愛感情や親近感を抱かせて金銭等をだまし取る詐欺、と説明されています。

【警察庁】令和8年(2026年)1月〜9月末の暫定値では、SNS型投資詐欺は7,580件、991.0億円です(2026年11月11日公表)。

【運営者の整理】令和8年の値は9か月分で、公表資料の表の構成も前年と違うため、令和7年とは比べていません。

この記事で使う言葉です。

  • 認知件数: 警察が把握した件数です。
  • 確定値・暫定値: 年間の数字を確定させた値と、その前の段階の値です。
  • 振り込め詐欺救済法: 詐欺などに使われた口座の残高から、被害者に支払う手続を定めた法律です。

出典: 警察庁の確定値資料・暫定値資料・SOS47、金融庁の類型ページ。

2. 登録業者を確かめる方法

【金融庁】日本の居住者を相手に金融商品取引行為を業として行う場合は、業者の所在地が海外でも、日本での登録が必要と書いています。

【運営者の整理】金融庁のページで確かめられる道具を、次の3つにまとめました。

  • 金融事業者一括検索: 登録等の状況を、業種をまたいで検索できます(令和8年1月30日に運用開始)。
  • 免許・許可・登録等を受けている事業者一覧: 業種別の一覧です。暗号資産交換業者は27業者です(令和8年9月30日現在)。
  • 無登録で金融商品取引業を行う者の名称等: 警告書を出した無登録業者の一覧です(令和8年11月10日更新のものを含め、一覧ごとに更新日が違います)。

【金融庁】無登録業者の一覧は、警告書を出した時点で無登録営業を確認できた者に限られます。載っていない者でも、無登録営業にあたる行為をしていることがあり得る、と書いています。

【金融庁】登録業者の名を騙る無登録業者もある、と書いています。類型ページには、登録番号の詐称や、既存の業者に似せた偽のウェブサイトの例があります。

【運営者の整理】検索で分かるのは、その名称の事業者が登録等を受けているかどうかまでです。連絡してきた相手がその事業者本人かどうかは、別に確かめる点です。

【日証協】相手が証券会社を名乗る場合の確かめ方として、その会社の公式ホームページに載っているコールセンター等への問い合わせを挙げています。

投資を始める前の全体の流れは、投資を始める前に、決めておくことにあります。

出典: 金融庁の一括検索のお知らせ・事業者一覧・無登録業者の一覧・総合注意喚起・類型ページ、日証協の注意喚起。

3. 警察庁・金融庁などが挙げる確認項目の見方

確認項目は、警察庁・金融庁・日証協(日本証券業協会)が別々のページで出しています。見る場面を表1にまとめました。

【警察庁】SOS47(警察庁の特殊詐欺対策ページ)は、6つのポイントに分けて、計10のチェック欄を載せています。主なものを運営者の言葉で要約すると、次のとおりです。

  • SNSのDMで投資に誘われ、連絡先がLINEなどに変わった
  • 紹介された業者が、金融庁の検索で登録業者として出てこない
  • 「確実」「あなただけ」といった言い方で勧められた
  • 著名人の名前を使った無料の投資教室で、本人の公式アカウントに発信がない
  • 勧められた暗号資産や投資アプリが、検索しても出てこない
  • 個人名義の口座へ振り込むよう求められた、または振込のたびに口座が変わる

【警察庁】1つでも当てはまったら、お金を振り込む前に警察に相談するよう呼びかけています。

【金融庁】類型ページは、勧誘の事例を9つ挙げています。動画投稿サイトの広告等からSNSの非公開のチャットへ誘導する例、政府公認をうたう例、証券口座を装ったスマホアプリの例などです。

【金融庁】いずれかに該当または類似する場合は、投資詐欺である可能性が高い、と書いています。

【金融庁】同じページは、該当するもの全てが投資詐欺とは限らず、全ての手法を網羅するものでもない、とも断っています。

【日証協】見分け方は6点で、これまでにない連絡方法、公式と違うユーザー名、個人名義の振込先などです。

【運営者の整理】3つの資料のどれにも出てくる点の1つが、振込先に個人名義の口座を指定される点です。

4. お金を求められたときの注意

【運営者の整理】個人名義の口座への振込は、機関によって書き方の強さが違います。

【国民生活センター】投資資金の振込先に個人名義の口座を指定された場合について、詐欺と明記し、振り込まないよう呼びかけています。【消費者庁】も同じ書き方です。

【警察庁】実際の投資の話であれば、個人名義の口座を指定されることや、振込のたびに口座が変わることは「まずありません」と書いています。

【金融庁】入金の際に、証券会社が個人名義の銀行口座を指定することはない、と書いています(類型ページ)。

【国民生活センター】出金しようとしたときに、手数料や税金の名目で先に支払を求められた相談事例を載せています。【警察庁】SOS47は、全額の引出しのために手数料などを求められる流れを書いています。

【金融庁】類型ページには、しばらくは利益が出て出金もできるように装いながら、追加で高額な入金をさせる例があります。

【金融庁】総合注意喚起は、被害を回復する代わりに別の商品の購入を求める勧誘を、例に挙げています。【国民生活センター】被害回復をうたう二次被害にあう可能性もある、と書いています。

出典: 国民生活センター、消費者庁、警察庁SOS47、金融庁の類型ページ・総合注意喚起。

5. 相談できる窓口は、どこか

【運営者の整理】資料に書かれた連絡先を、振込の前後で分けました。

  • 振り込む前から相談できる窓口: 警察(#9110)、金融庁の相談ダイヤル、消費者ホットライン(188)

【預金保険機構】電話の受付は9時30分〜18時で、土日・祝日・年末年始を除きます。機構に問い合わせても、あらためて警察と振込先の金融機関に連絡することになる、と書いています。

【日証協】被害防止コールセンター(0120-344-999)は被害の未然防止が目的で、被害回復を目的とした窓口ではない、と書いています。

【証券取引等監視委員会】情報提供窓口は、個別のトラブル処理・調査等の依頼には対応していない、と書いています。

6. 口座の凍結と、被害回復の仕組み

【金融庁】振り込め詐欺救済法の正式名は「犯罪利用預金口座等に係る資金による被害回復分配金の支払等に関する法律」です。預金口座等への振込みが利用された詐欺等の被害が対象です。

【金融庁】SNS型投資詐欺・ロマンス詐欺も、預金口座等への振込みによる被害は対象になる、と書いています。

【預金保険機構】預金口座等への振込みが利用されていない場合は、救済法の対象外と書いています。機構の説明を、運営者が次の5段階に整理しました。

  1. 被害に気づいたら直ちに、警察と振込先の金融機関に連絡し、口座の取引の停止を依頼する
  2. 金融機関が調べたうえで、振込先の口座を凍結する
  3. 金融機関の依頼を受けて、預金保険機構が公告する(対象の口座をウェブサイトで知らせること)
  4. 被害者が、振込先の金融機関に支払を申請する
  5. 金融機関から、被害回復分配金が支払われる可能性がある

【運営者の整理】この仕組みでの支払は、保証されるものではありません。

【金融庁】犯人が預金口座等からお金を引き出してしまうと、支払は受けられません。被害にあったお金が全額支払われない場合や、支払が行われない場合もある、と書いています。

【金融庁】支払の原資は口座の残高です。申請された被害額の総額が残高を超えるときは、残高を被害額の割合で分けます(按分)。残高が1,000円未満の場合は、支払は行われません。

【金融庁】申請期間は、支払手続が開始された旨の公告があった日の翌日から30日以上です。期間内に申請できないと支払は受けられず、期間は金融機関から個別に連絡される、と書いています。

【預金保険機構】概要資料(平成27年3月末時点の数値を含みます)は、30日以上が法令上の下限で、実際の手続では支払申請期間を60日以上で取り扱っている、と書いています。

【金融庁】支払までに少なくとも半年以上かかるのが一般的、と書いています。

出典: 金融庁の救済法のページ、預金保険機構の2ページ。

7. 資料に書かれていないこと

次の点は、確認した資料に書かれていませんでした。個別の事情は、表2の窓口で確認してください。

  • クーリング・オフ: SNSで勧められた投資の話に使えるかどうか。
  • 暗号資産・現金で渡した場合: 連絡先と手順。救済法は預金口座等への振込みが対象で、暗号資産の送信を名指しした文は見つかっていません。
  • 連絡までの時間の目安: 預金保険機構のページにあるのは「直ちに」という語までです。
  • 消費者ホットライン188の受付時間。
  • お住まいの都道府県での、#9110の受付時間。

勧められた商品が実在する投資信託だと分かった場合でも、勧めてきた相手が登録を受けた事業者か、振込先が正規のものかは、別に確かめる必要があります。商品そのものの費用や対象制度の見方は、話題のテーマ型ファンドや株価指数を買う前に確かめること——集中度・費用・NISAの対象・為替の見方で整理しています。商品が実在することは、勧誘が適切であることを示しません。

この記事は、投資話の真偽を判定するものでも、法律・金融の個別相談でもありません。確認項目に当てはまらないことは、被害にあわないことを示すものではありません。

おわりに

読み終えたあとに確かめられる点は、次の2つです。

  • 電話番号と受付時間は、参照元の各ページで最新の表記を確かめられます。
  • 振込先の口座の公告は、預金保険機構の公告のサイトで確かめられます。
